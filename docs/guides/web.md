# Web 配置与预览

部署完成后访问 `http://127.0.0.1:8765`。Web 与 CLI 共用配置、操作锁和录制保护；
不要为同一部署同时启动多个管理服务。安装和远程访问见[部署指南](deployment.md)。

## 配置相机

1. **扫描设备**：从 Linux USB sysfs 读取型号和身份；型号不明确时不允许猜测绑定。
   Gemini 305 仅供 Rust 后端使用，其他型号以档案与后端支持范围为准。
2. **绑定逻辑槽位**：从当前槽位型号对应的设备中选择序列号。更换槽位型号或后端需先按[配置指南](configuration.md#准备部署配置)准备 inventory，Web 暂不提供切换。
   命名空间和光学帧前缀独立填写，不能冲突。
3. **保存参数**：填写实机支持的流、尺寸、FPS、格式、时间来源和健康策略。
   官方后端可编辑其允许的曝光/增益；Rust 后端拒绝未实现的参数，见[后端限制](rust-backend.md)。
4. **启用设备**：只有启用设备参与正式采集，默认模板均未启用。

保存会使相关相机的旧确认失效，并停止其不再匹配的预览；共享配置变化可能使全部
确认失效。保存不重启正式服务，多窗口旧 revision 会被拒绝，需重新读取后再编辑。

## 预览与档位确认

正式服务停止后，启动所选相机的临时预览容器。预览订阅真实 ROS Image，提供彩色
JPEG 与深度伪彩色；可以逐台预览并切换查看。

执行“检查出帧并确认此档位”时，管理器核对当前配置、镜像与容器实例，再检查所有
启用流的消息布局、尺寸、帧率、时间推进、新鲜度和 QoS。检查通过才保存确认。
确认后可以启动采集；录制完整性仍按[录制指南](recording.md)单独检查。

JPEG 编码最高每流 5 FPS；宽度超过 960 像素时仅缩放显示副本，不修改正式图像。
深度伪彩显示范围为 0.2–3.0 m，无效值为黑色。
超过 3 秒无新图像时不再展示旧帧。临时目录 `work/web-preview/` 只保留最新画面，
不能作为录制数据集。

浏览器停止请求状态约 120 秒后，管理器回收预览；管理进程异常退出时，容器内租约
也会有界结束采集。正常停止会等待驱动退出后移除容器。

## 正式运行

全部启用设备完成确认后，先停止所有预览，再执行“检查并启动相机组”。管理器逐台
启动和检查，最后复查整组。正式采集不会隐式抢占预览或重启已健康的相机。

已有录制保护时不能修改配置、启动预览或停机。任务失败通过状态和“查看日志”定位，
日志可能包含运行信息，不要公开上传。常见问题见[故障排查](troubleshooting.md)。

Web 是管理入口，不是常驻 ROS 数据网关；停止 Web 不应被当作相机录制已结束。
整组停机应使用[受管生命周期命令](lifecycle.md)。

## 界面以外的功能

IMU 配置需要编辑 inventory；原生录制需要独立服务配置或测试工具，Web 没有录制／恢复表单。
“采集质量事实”按钮显示查询摘要，不启动录制。操作入口见[IMU 配置](configuration.md#rust-相机-imu)
和[录制指南](recording.md)。完整能力及未完成的实机验收见[当前状态](current-status.md)。
